# وتيرة (Wateerah) 🌿
> نظام إدارة الحياة الشخصي — صمّم إيقاع يومك بتجرد وانسيابية.

**وتيرة** هي منصة برمجية (SaaS) متكاملة وتطبيق ويب تقدمي (PWA) مصمم لمساعدة المستخدمين على إدارة حياتهم الشخصية، المالية، والعملية في مساحة واحدة. تتميز المنصة بتصميم عصري مستوحى من جماليات أنظمة **iOS** (تأثيرات زجاجية شفافة Glassmorphism، حواف ناعمة، وواجهة خالية من التشتت).

---

## ✨ الميزات الرئيسية

### 🛠️ أدوات مساحة العمل (Workspace)
* **لوحة الأهداف الواقعية (Corkboard Vision Board):** لوح خشبي تفاعلي لتثبيت الصور والأهداف مع تتبع نسبة الإنجاز والمهام الفرعية.
* **المهام المتنقلة (Kanban Board):** لوحة عمل متقدمة مقسمة إلى حالات (فكرة، مجدول، قيد التنفيذ، مكتمل) مع تحديد الأولوية (عاجل، غير عاجل، غير مهم).
* **إدارة المالية الشاملة:** تتبع الحسابات والمحافظ البنكية، قائمة الأمنيات (Wishlist)، متتبع الاشتراكات الشهرية، وحاسبة التوزيع الذكية للدخل.
* **بوصلة التركيز:** أداة لتحديد وتثبيت الهدف الأهم لليوم.
* **متتبع العادات:** بناء ومتابعة الروتين اليومي بسهولة.
* **مساحة الصفاء:** دفتر يوميات للتدوين الحر وتفريغ الأفكار.

### 🎨 تجربة المستخدم والتصميم (UI/UX)
* **تأثيرات زجاجية (Glassmorphism):** تصميم يدمج بين الشفافية والعمق البصري.
* **تطبيق ويب تقدمي (PWA):** قابل للتثبيت مباشرة على شاشات هواتف أبل (iOS) وأندرويد كتطبيق مستقل بشاشة كاملة.
* **تخصيص المظهر:** دعم كامل للوضع الفاتح (ورق دافئ)، النقي (Minimal)، والداكن (سكون ليلي)، مع تأثيرات إضاءة متكيفة حسب الوقت (صباح/مساء).
* **سحب وإفلات (Drag & Drop):** إمكانية ترتيب الأدوات في مساحة العمل وتغيير حالات المهام بالسحب والإفلات.

### 👑 نظام الإدارة والاشتراكات (SaaS Features)
* **التجربة المجانية:** نظام ذكي يمنح الحسابات الجديدة تجربة مجانية لمدة يومين لمرة واحدة فقط.
* **إدارة الاشتراكات بالأكواد:** تفعيل وتجديد الباقات عبر أكواد فريدة يتم توليدها من لوحة التحكم (بالأيام).
* **إشعارات السحابة الزجاجية:** نظام إشعارات فوري (يشبه تطبيق بابل) يسمح للمدير بإرسال رسائل أو مسابقات مؤقتة لجميع المستخدمين، أو لمستخدم محدد عبر الإيميل أو المعرف (UID).
* **لوحة تحكم إدارية:** لإدارة المستخدمين، تعديل الاشتراكات، وتوليد الأكواد وإرسال الإشعارات.

## 💻 التقنيات المستخدمة (Tech Stack)

تم بناء المشروع بالاعتماد على هندسة الوحدات (Modular Architecture) لضمان الأداء العالي وسهولة الصيانة:

* **واجهة المستخدم (Front-end):**
  * HTML5 (Semantic Structure)
  * CSS3 (Vanilla CSS with CSS Variables & Glassmorphism)
  * JavaScript (ES6 Modules)
* **الخلفية وقاعدة البيانات (Back-end / BaaS):**
  * Firebase Authentication (نظام تسجيل الدخول والمصادقة والتحقق من البريد).
  * Firebase Firestore (قاعدة بيانات NoSQL سحابية للحفظ الفوري).

## 📂 هيكلة المشروع (Project Architecture)

المشروع مقسم باحترافية لفصل المهام (Separation of Concerns):

```text
wateerah/
├── index.html                 # الواجهة الرئيسية والهيكل
├── README.md                  # توثيق المشروع
└── assets/
    ├── css/
    │   ├── variables.css      # الألوان، الثيمات، والشفافية
    │   ├── base.css           # الإعدادات العامة والخطوط
    │   ├── layout.css         # تخطيط الشبكة (Grid) والهيدر
    │   └── components.css     # تصميم النوافذ، الأزرار، والبطاقات
    └── js/
        ├── firebase-config.js # إعدادات الاتصال بفايربيس
        ├── auth.js            # المصادقة وإدارة الحسابات
        ├── ui.js              # تفاعلات الواجهة والنوافذ المنبثقة
        ├── widgets.js         # منطق الأدوات (المهام، المالية، الخ)
        ├── admin.js           # لوحة الإدارة والإشعارات السحابية
        └── main.js            # ملف الربط والتشغيل الرئيسي
